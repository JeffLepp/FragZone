# Product

## Users

Desktop browser players using keyboard and mouse, including players on older laptops and integrated graphics. They want to enter a match quickly and maintain responsive aim, movement, and combat without installing a native client.

## Product Purpose

FragZone is a lightweight, browser-based free-for-all FPS inspired by Counter-Strike: Source. Success means the game feels immediate, legible, gritty, and consistently smooth while remaining inexpensive to host and modest in its client hardware requirements.

## Brand Personality

Gritty, direct, competitive. The interface should feel utilitarian and game-native rather than polished into a generic modern web application.

## Anti-references

Avoid cinematic post-processing, decorative UI choreography, glossy esports styling, glass-heavy overlays, and visual effects that reduce target clarity or add noticeable GPU cost. Avoid replacing the current Source-era character with a generic dashboard aesthetic.

## Design Principles

- Protect frame time before adding decoration.
- Keep combat information immediate and readable.
- Let the gritty arena and responsive controls carry the personality.
- Make quality tradeoffs explicit and reversible on weaker hardware.
- Prefer small, purposeful feedback over persistent visual effects.

## Accessibility & Inclusion

Keep keyboard interaction and focus states usable outside pointer lock. Respect reduced-motion preferences for nonessential HUD animation, preserve readable contrast, and ensure optional visual treatments never carry gameplay-critical information by themselves.
